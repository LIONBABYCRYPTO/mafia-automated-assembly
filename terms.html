2. Description of Service

Werewolf is a free, browser-based social deduction game designed for in-person group play. The Game operates as follows:

  • Players join game rooms hosted by a designated game host.
  • Each player receives a secret role assignment (e.g., Villager, Werewolf, Seer, Doctor).
  • The Game alternates between night phases (where special roles act secretly) and day phases (where all players discuss and vote).
  • The Game ends when one team meets its win condition.
